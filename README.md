# Vox

Голосовой помощник стримера для Windows: висит в трее, слушает микрофон и

- оживляет аватар в OBS (говорит, кричит, смеётся, грустит, удивляется, поёт);
- кормит аватар на донат (по звуку алерта в OBS);
- считает мат и выводит число на стрим через файл для OBS.

Всё распознаётся локально (sherpa-onnx: CED-small для звуков, zipformer-ru для слов), в интернет уходит только проверка обновлений на GitHub.

## Установка

Скачай `Vox-Setup-<версия>.exe` со страницы [релизов](https://github.com/denprog5/vox/releases) и запусти. Права администратора не нужны. Дальше Vox обновляется сам.

Подробно: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).
